P-06 Manufacturing · Shop floor

Andon Shop-Floor Visual Management

Bottlenecks, stoppages and maintenance calls weren’t visible to everyone on the floor in real time.

  • Andon
  • SignalR
  • Live dashboards
  • PLC I/O

The requirement

The problem to solve

Line status, bottlenecks and maintenance calls were not visible to the whole floor as they happened, slowing the response.

The application

How the system works

Overhead 65-inch line displays showing live throughput, takt-time progress, Andon cord pulls and maintenance response timers — driven by a SignalR hub with colour-coded status and audible alarms for critical faults.

Workflow

Each step the application handles, in order.

  1. 01Andon buttons + PLC I/O
  2. 02SignalR hub
  3. 03Line displays
  4. 04Audio alarms
  5. 05Analytics DB

Key capabilities

  • Distributed clients updated over SignalR / WebSockets
  • Colour-coded status: green normal, yellow warning, red stoppage
  • Audible alarm for critical faults
  • Takt-time progress synchronised with the assembly conveyor

Hardware & interfaces

  • 65-inch industrial displays
  • Raspberry Pi / Intel NUC client nodes
  • Wireless Andon push-button stations

Software & frameworks

  • C# WPF full-screen client / web dashboard
  • ASP.NET Core SignalR hub
  • PLC digital I/O reader
  • PostgreSQL analytics database

Software scope

Live status distribution, display clients, event timers and production history.
