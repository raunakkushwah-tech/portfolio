High-Speed Conveyor RFID Encoding

Each pallet needed unique genealogy data written to its RFID tag — without slowing or stopping the conveyor.

  • UHF RFID
  • LLRP
  • Encoder sync
  • C# concurrency

The requirement

The problem to solve

Every pallet needed its component genealogy written to an RFID tag on the move, without stopping or slowing the conveyor.

The application

How the system works

An inline UHF RFID cell that uses rotary-encoder position to trigger the antenna, writes 96-bit EPC data to moving pallet tags, verifies each write by reading it back, and ejects pallets whose tags fail or respond with a weak signal.

Workflow

Each step the application handles, in order.

  1. 01Encoder position
  2. 02Antenna trigger
  3. 03EPC write (LLRP)
  4. 04Read-back verify
  5. 05Reject diverter

Key capabilities

  • Rotary encoder pulses locate the pallet and trigger the antenna
  • LLRP commands write 96-bit EPC memory without stopping the line
  • Read-after-write verification before the pallet leaves the antenna field
  • Automatic rejection when a write fails or RSSI is too low

Hardware & interfaces

  • Zebra FX9600 4-port UHF reader
  • Far-field RFID antenna
  • Autonics incremental rotary encoder
  • SMC high-speed pneumatic ejector

Software & frameworks

  • C# LLRP reader interface
  • Multithreaded producer–consumer queue
  • EPC hex encoding utilities
  • SQL part-genealogy database

Software scope

Reader communication, EPC encoding, read-back checks and tag history.
