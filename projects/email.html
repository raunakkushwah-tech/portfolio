P-04 Manufacturing · Production reporting

Automated Shift Production Reports

Daily output, scrap and OEE were logged by hand on paper, taking time and inviting errors.

  • C# service
  • Excel & PDF
  • OEE
  • SMTP

The requirement

The problem to solve

Line output, scrap and downtime were recorded manually on paper every shift — slow, error-prone and hard to analyse.

The application

How the system works

A scheduled reporting service that runs at the end of each shift, aggregates production, scrap, downtime and station pace from SQL, calculates OEE, and emails multi-tab Excel workbooks and PDF summaries with charts — over authenticated SMTP with a backup relay.

Workflow

Each step the application handles, in order.

  1. 01Shift end
  2. 02SQL aggregation
  3. 03OEE calculation
  4. 04Excel + PDF
  5. 05Email delivery

Key capabilities

  • Scheduler triggered at the end of each shift rotation
  • SQL aggregation of output vs scrap, downtime and station pace
  • Headless PDF summaries with embedded charts plus multi-tab Excel
  • TLS-authenticated SMTP with backup relay failover

Hardware & interfaces

  • Central plant database server
  • Virtual machine host

Software & frameworks

  • C# .NET scheduled service
  • EPPlus (Excel)
  • QuestPDF / iText
  • SQL Server stored procedures

Software scope

Scheduled data extraction, report generation, email delivery and execution logging.
