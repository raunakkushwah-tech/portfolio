YG8 End-of-Line Quality & Safety Station

Operators needed a fast inspection station that checks station readiness before inspection.

  • WPF touchscreen
  • Mitsubishi PLC
  • Safety interlocks
  • Live charts

The requirement

The problem to solve

The YG8 line needed a quick operator inspection station that could show interlock status before inspection, and that stayed readable on a high-glare shop floor.

The application

How the system works

A dedicated inspection station with dual-channel safety light curtains, pneumatic locks and a high-contrast touchscreen WPF interface. Seating-pressure curves are plotted live against threshold envelopes, and results are committed to SQL only after the physical interlock releases.

Workflow

Each step the application handles, in order.

  1. 01Light curtain state
  2. 02PLC memory bits
  3. 03Pressure curve check
  4. 04Interlock release
  5. 05SQL commit

Key capabilities

  • Safety light-curtain state read directly from PLC memory bits
  • Touchscreen UI designed for high-glare shop-floor readability
  • Live seating-pressure curves with threshold envelopes
  • Database transaction committed only after the interlock releases

Hardware & interfaces

  • Mitsubishi FX5U PLC
  • Banner safety light curtains
  • Pressure transducers (4–20 mA)
  • 21-inch industrial touch PC

Software & frameworks

  • .NET Framework 4.8 / WPF
  • MX Component PLC driver
  • OxyPlot real-time curves
  • Entity Framework Core

Software scope

Operator interface, pressure-curve display, interlock-status display and SQL result records.
